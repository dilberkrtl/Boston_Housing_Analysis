# Boston Housing Analysis

## Overview

This project explores the Boston Housing dataset using several regression techniques implemented with Python and scikit-learn.

The project focuses on comparing Linear Regression, Ridge Regression, and Lasso Regression models and evaluating their performance on training and test data.

The notebooks use the extended Boston Housing dataset provided by `mglearn`, which contains 506 samples and 104 features.

The project also includes the original `boston.csv` dataset, which contains 506 observations and 16 columns.

## Project Structure

## Dataset

The project reads `boston.csv` using Pandas.

The dataset contains 506 observations and 16 columns:

- `TOWN`
- `TRACT`
- `LON`
- `LAT`
- `MEDV`
- `CRIM`
- `ZN`
- `INDUS`
- `CHAS`
- `NOX`
- `RM`
- `AGE`
- `DIS`
- `RAD`
- `TAX`
- `PTRATIO`

The notebook uses `boston.info()` to inspect the dataset.

The regression models use the extended Boston dataset loaded with:

    mglearn.datasets.load_extended_boston()

The resulting feature and target dimensions are:

    X shape: (506, 104)
    y shape: (506,)

## Data Preparation

The extended dataset is divided into training and test sets using `train_test_split`.

The notebooks use:

    random_state=0

This ensures that the same train/test split can be reproduced.

## Models

### Linear Regression

The `Boston_Housing_Linear_Regression.ipynb` notebook uses `LinearRegression` from scikit-learn.

The model is trained on the training data and evaluated using R² scores.

Results recorded in the notebook:

    Training R²: 0.952051960903273
    Test R²:     0.6074721959665883

The difference between the training and test scores indicates overfitting.
